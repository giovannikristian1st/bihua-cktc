⚙️ Pengaturan Server (GAS URL)

Jika Anda menyalin file Google Sheet ke akun Drive lain, masukkan URL App Script yang baru di sini.

Cara Deploy App Script & Excel Sendiri

  1. Buka Google Sheet Template dan buat salinan ke Google Drive Anda (File -> Buat salinan / Make a copy).
  2. Di file salinan Anda, klik menu Ekstensi > Apps Script.
  3. Hapus semua kode yang ada, lalu copy paste kode App Script yang diperlukan ke sana. (Pastikan Anda sudah memiliki kodenya).
  4. Klik tombol Terapkan (Deploy) di sudut kanan atas > Deployment baru.
  5. Pilih jenis Aplikasi Web.
  6. Atur "Akses ke aplikasi" menjadi Siapa saja (Anyone).
  7. Klik Terapkan dan berikan otorisasi akses (jika diminta, pilih akun Anda > Lanjutan > Buka... tidak aman).
  8. Copy "URL Aplikasi Web" yang dihasilkan.
  9. Paste URL tersebut ke dalam kolom "URL App Script (Custom)" di halaman Options ini, lalu klik Simpan.
